ÍNDICE DE PACOTES E COMPONENTES UTILIZADOS NA EXTENSÃO KNIME
--------------------------------------------------------------------------------

1. DEPENDÊNCIAS PYTHON DIRETAS (RUNTIME DA EXTENSÃO)
   • Pandas (v2.0+)
     - Licença: BSD 3-Clause
     - Autores: Wes McKinney e comunidade Pandas / NumFOCUS
     - Função no TopoQ KNIME: Manipulação de tabelas, DataFrames, extração e
       estruturação das propriedades calculadas (HOMO, LUMO, Dipolo, Calor de Formação)
       e junção de metadados moleculares.

   • KNIME Python Extension API (knime-python-base 5.4 & knime-extension 5.4)
     - Licença: Eclipse Public License 2.0 (EPL-2.0) / GNU Lesser General Public License
     - Mantenedor: KNIME AG
     - Função no TopoQ KNIME: Framework oficial de nós em Python puro para o KNIME
       Analytics Platform (knime.extension, knext.node, knext.parameter, knext.Table).

   • KNIME Chemistry Types (knime.types.chemistry / org.knime.features.chem.types)
     - Licença: Eclipse Public License 2.0 (EPL-2.0)
     - Mantenedor: KNIME AG / Comunidade Química KNIME
     - Função no TopoQ KNIME: Suporte a portas e células moleculares químicas
       nativas no KNIME (SdfValue, MolValue).

2. AMBIENTE DE EXECUÇÃO PYTHON
   • Python Runtime (v3.11)
     - Licença: Python Software Foundation License (PSFL)
     - Mantenedor: Python Software Foundation (PSF)
     - Função no TopoQ KNIME: Interpretador da linguagem de programação.

   • Módulos Nativos da Biblioteca Padrão Python (Python Standard Library)
     - math (cálculos de distâncias interatômicas euclidianas 3D e tolerâncias covalentes)
     - logging (registro estruturado de eventos, alertas e diagnósticos no console do KNIME)
     - concurrent.futures (gerenciamento de pool de threads e paralelismo de workers MOPAC)
     - subprocess (acionamento controlado de executáveis externos via linha de comando)
     - re, os, sys, pathlib, shutil, tempfile, threading, time (manipulação de sistema de
       arquivos, pastas temporárias por molécula e leitura de saídas).

3. FERRAMENTAS CIENTÍFICAS EXTERNAS (PROCESSOS ISOLADOS - NÃO DISTRIBUÍDOS)
   • MOPAC (OpenMOPAC)
     - Licença: Apache License 2.0
     - Autores: Stewart Computational Chemistry / Molecular Sciences Software Institute (MolSSI)
     - Função: Motor semiempírico mecânico-quântico externo acionado via linha de comando.
     - Nota: O MOPAC NÃO é distribuído junto com esta extensão. É instalado
       separadamente pelo usuário e invocado estritamente como subprocesso independente
       (subprocess.Popen).

   • Open Babel
     - Licença: GNU General Public License v2.0 (GPL-2.0)
     - Autores: Geoff Hutchison, Chris Morley, Noel O'Boyle e comunidade Open Babel
     - Função: Conversão de formatos moleculares químicos (obabel.exe) via linha de comando.
     - Nota: O Open Babel NÃO é redistribuído nem empacotado na extensão. Não há
       linkagem estática ou dinâmica (sem bibliotecas .dll / .so linkadas).

4. FERRAMENTAS DE COMPILAÇÃO E EMPACOTAMENTO
   • knime-extension-bundling (v5.4)
     - Licença: Eclipse Public License 2.0 (EPL-2.0) / Ferramentas auxiliares BSD/MIT
     - Mantenedor: KNIME AG
     - Função: Criação do ambiente conda autocontido e empacotamento do repositório
       p2 / update-site para instalação no KNIME 5.4.
